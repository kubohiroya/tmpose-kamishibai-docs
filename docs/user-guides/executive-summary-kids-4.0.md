Copyright © 2026 Hiroya Kubo. この文書は[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)で提供します。

この説明は、TMPose紙芝居4.0で遊ぶ人、作品を作ってみたい人のために書いています。むずかしい台本の
書き方や道具の使い方を知らなくても読めます。

使う作品が4.0用かどうかは、始める前に先生や家の人といっしょに確認してください。

## これは何？

TMPose紙芝居4.0は、絵、音、セリフ、動きを組み合わせたデジタル紙しばいです。

お話を見るだけでなく、キーを押したり、画面にさわったり、カメラの前でポーズをとったりして、物語に
参加できます。何をするとお話が進むかは、作品によってちがいます。

このアプリでは、次の三つを楽しめます。

| 楽しみ方 | できること                                         |
| -------- | -------------------------------------------------- |
| 見る     | 絵、登場人物、セリフ、音、動きでお話を楽しむ       |
| 動く     | ポーズ、キー、画面のタッチでお話に参加する         |
| 作る     | お話、絵、音、参加する場面を考えて一つの作品にする |

## 見る — お話を楽しもう

作品を開くと、表紙のあとに場面が順番に進みます。登場人物が話したり、動いたり、背景や音が変わったり
します。途中で選び方が出る作品では、選んだ答えによって次の場面が変わることもあります。

遊ぶ前に、先生や家の人と次のことを確認しましょう。

- 音の大きさはちょうどよいか
- 画面が見やすい場所にあるか
- キーや画面のタッチだけでも遊べるか
- カメラを使う作品か
- 終わりたいときに、どうやって止めるか

画面が見にくい、音が聞きにくい、体を動かしにくいときは、がまんしないで伝えてください。文字を
読み上げてもらう、音を小さくする、キーや画面のタッチを使うなど、自分に合う参加方法を選べます。

## 動く — ポーズで参加しよう

ポーズを使う作品では、画面に出る案内を見て、カメラの前で体を動かします。アプリがポーズを読み取ると、
登場人物の絵や音が変わったり、次の場面へ進んだりします。

ポーズを読み取ってもらうコツは、次のとおりです。

- 明るい場所でやる
- 体がカメラに入る位置に立つ
- 案内と同じ向きか、画面の左右が反対に見えていないか確かめる
- ポーズをとったら、少し止まる
- ほかの人がたくさん映らないようにする

うまく読み取ってもらえなくても、まちがいではありません。明るさ、服、背景、カメラからのきょりなどで、
読み取り方は変わります。何度も同じ動きをするのがつらいときは、キーや画面のタッチで進める方法を大人の
人に聞いてください。

カメラを使いたくないときや、体を動かすのがむずかしいときは、ポーズをしなくてもよい参加方法を選びます。
いやなポーズや、いたい動きをする必要はありません。

## 作る — 自分たちの物語を考えよう

紙しばいを作るときは、まず道具の使い方ではなく、どんなお話にしたいかを考えます。

| 考えること | たとえば                                   |
| ---------- | ------------------------------------------ |
| お話       | だれが、どこで、何をする？                 |
| 場面       | はじまり、できごと、おわりをどう分ける？   |
| 登場人物   | 主人公、友だち、動物など、だれを出す？     |
| 絵         | 背景や登場人物をどんな見た目にする？       |
| 音         | セリフ、音楽、成功したときの音をどうする？ |
| 参加       | どこでキー、タッチ、ポーズを使う？         |
| 分かれ道   | 選び方によって、お話をどう変える？         |
| 安全       | だれでも無理なく参加できる？               |

考えた内容は、場面ごとに紙やカードへ書き出せます。そのあとで、作品を作る人が、絵や音といっしょに
「作品フォルダー」へまとめます。物語が長いときは、章や場面ごとに台本を分けても、一つのお話として
確かめられます。

台本は、YAMLという整理された書き方で保存されます。最初からその書き方を覚える必要はありません。
まず「どの場面で、だれが、何をするか」を自分の言葉で書き、大人の人やくわしい人といっしょに台本へ
していきます。

作品をためす道具は、書きかけやまちがいを見つけると、どこを直せばよいか知らせます。まちがった内容を
そのまま始めず、前に正しく動いていた作品を残したまま直せます。直したあとは、最初から、今の場面から
など、どこからためすかを選べます。

## みんなで作るときの役わり

グループでは、できることや好きなことに合わせて役わりを分けられます。

| 役わり     | やること                                 |
| ---------- | ---------------------------------------- |
| お話係     | 物語とセリフを考える                     |
| 絵係       | 背景や登場人物を作る                     |
| 音係       | 音楽や効果音を選ぶ                       |
| 参加方法係 | キー、タッチ、ポーズを考える             |
| 台本係     | 場面と動きを台本へまとめる               |
| 安全係     | カメラ、音、動く場所、個人情報を確認する |
| テスト係   | いろいろな人が無理なく遊べるかためす     |

一人でいくつかの役をしても、途中で役を交代しても大丈夫です。カメラに映る役を、いやがる人へむりに
たのんではいけません。

## カメラと個人情報のやくそく

カメラは、ポーズを読み取るために使います。使う前に、先生や家の人と「なぜカメラを使うのか」「どこまで
映るのか」を確認してください。

- 知らないWebページでは、カメラの使用をすぐに許可しない
- 自分や友だちの顔が映ってよいか、先に確かめる
- 家の中、名札、手紙、学校名など、見せたくないものが後ろにないか確かめる
- 本当の名前、学校、住所、電話番号、パスワードを台本や入力らんへ書かない
- 友だちが映った画面を、許可なく写真や動画にしない
- 終わったら作品を止め、カメラが止まったことを大人の人と確かめる

カメラを選ぶ機能や、画面の左右を反対に見せる機能がある作品もあります。どのボタンか分からないときは、
手当たりしだいに押さず、大人の人に聞いてください。端末のカメラを見分けるための情報を、紙しばいの台本へ
書いておく必要はありません。

## まわりの安全のやくそく

ポーズを始める前に、自分とまわりの人が安全かを確かめます。

- つくえ、いす、かばん、ケーブルからはなれる
- 手を広げても人や物にぶつからない場所を作る
- すべりやすい場所や、だんさに気をつける
- いすやつくえの上に乗らない
- 大きく走ったり、高くジャンプしたりするポーズを選ばない
- つかれた、いたい、こわいと感じたら、すぐに止まる
- 大きな音で耳がいたくならないようにする

せまい場所では、立ったまま大きく動く代わりに、手だけのポーズ、すわってできるポーズ、キー、画面の
タッチを使います。お話よりも、みんなの安全が一番大切です。

## 困ったとき

困ったときは、次の順番で行動します。

1. 動くのを止め、カメラから少しはなれます。
2. 先生、家の人、会場のスタッフなど、近くの大人へ伝えます。
3. 画面に出た言葉を、消す前に大人の人へ見せます。
4. 大人の人といっしょに、作品を止めるか、もう一度ためすかを決めます。

とくに、次のときは自分だけで続けません。

- 知らないページからカメラ、マイク、個人情報を求められた
- 映したくない人や物がカメラに入った
- 体がいたい、気分が悪い、こわいと感じた
- 何度ためしてもポーズが読み取られない
- エラーのような言葉が出て、どうすればよいか分からない
- 音、キー、画面のタッチが止まらない

困ったときに助けを求めることは、失敗ではありません。安全に止められることも、上手な使い方の一つです。

## どんな作品を作れる？

- 昔話の主人公を助ける紙しばい
- 学校や町を案内する紙しばい
- 防災の行動を選ぶ紙しばい
- 英語や手話であいさつする紙しばい
- 動物や宇宙について学ぶ紙しばい
- キーやタッチだけでも楽しめる紙しばい
- すわったまま参加できる紙しばい

大切なのは、「見る人が、どこで、どんな方法なら安心して参加できるか」を考えることです。

## まとめ

TMPose紙芝居4.0では、お話を「見る」、キーやタッチやポーズで「動く」、自分たちの物語を「作る」ことが
できます。

カメラを使うかどうかや、どの方法で参加するかは選べます。個人情報とまわりの安全を守り、困ったときは
一人で続けず、大人の人へ相談しましょう。

まずは一つの短い場面から始めてみましょう。短くても、みんなが安心して参加できれば、りっぱな作品です。
